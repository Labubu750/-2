# MIRAMAR HOTEL & SPA — Статический шаблон

Файлы:
- index.html — основная страница (включает структуру и форму).
- style.css — ваши стили (уже готовы).
- main.js — ваш JS (уже готов).

Как запустить локально:
1. Положите `index.html`, `style.css` и `main.js` в одну папку.
2. Откройте `index.html` в браузере (двойной клик или Drag&Drop).
3. Для локального сервера (рекомендуется при разработке): `npx http-server` или `python -m http.server` в папке с файлами, затем открыть http://localhost:8080.
